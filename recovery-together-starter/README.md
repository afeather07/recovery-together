# Recovery Together

A mobile-first peer-support website for adults preparing for or recovering from 7-OH and concentrated kratom products.

## Current version

This starter includes:

- Polished landing page
- Low-cognitive-load onboarding
- Anonymous profile preview
- Stage-based community room preview
- Safety messaging
- Responsive mobile design

## Run locally

Open `index.html` in any browser.

## Deploy

This static version can be deployed immediately with Vercel, Netlify, GitHub Pages, or any basic web host.

## Important

This project is peer support only. It is not a medical detox service, treatment provider, or source of individualized medical advice.
