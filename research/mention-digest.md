# Mention digest

Ongoing log of public web/news/forum mentions of 7-OH, kratom withdrawal, and related search terms, gathered via periodic web search. Purpose: surface things Aaron might want to personally respond to as the founder — nothing here is ever posted automatically. See `research/growth-workstreams.md` for why this stays human-in-the-loop by design.

**Real limits, stated plainly:** this is web-search-based, not a live crawler with API access to Reddit/TikTok/Instagram/Facebook internals — it only surfaces what's publicly indexed and findable via search, on whatever cadence a scheduled job actually runs (session-dependent, see below). It will miss things, especially real-time social chatter and closed groups. Treat it as a useful sweep, not a guarantee of "every mention."

**Scheduling limit:** the recurring search job only runs while this Claude Code session stays alive, and auto-expires after 7 days regardless — it is not a permanent standing service. Ask Claude to renew it after that if it's still useful.
